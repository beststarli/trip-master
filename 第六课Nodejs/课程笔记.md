# 第六课Node.js——个人记录
## Node.js是什么
- Node.js是基于V8引擎的JavaScript运行环境
- Node.js允许JavaScript代码在服务器端运行，可以处理输入/输出、网络请求和数据库操作等

## Node.js应用场景
- 服务端应用
- 工程化工具集
- 桌面端应用

### 数据聚合层——BFF层
介于前端和后端的中间层，用于聚合后端提供的数据，整理完成后再提供给前端使用

由于BFF是前端接触较多，所以通常选用Node.js来实现

## npm使用
- npm install：用于安装模块或依赖项
- npm uninstall：用于卸载模块或依赖项
- npm update：用于更新模块或依赖项
- npm search：用于搜索模块
- npm init：用于初始化一个新的Node.js项目
- npm publish：用于发布一个Node.js模块

## Node.js特性
- 单线程
- 异步，非阻塞I/O
- 事件驱动
- 模块化
- 跨平台
